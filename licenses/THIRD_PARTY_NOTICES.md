# 제3자 글꼴 고지

## Monaspace Argon 1.400

- 원본: https://github.com/githubnext/monaspace
- 사용 배포본: https://github.com/githubnext/monaspace/releases/tag/v1.400
- 저작권: Copyright (c) 2023, GitHub
- 라이선스: SIL Open Font License 1.1
- Reserved Font Names: Monaspace, Argon, Neon, Xenon, Radon, Krypton

Argontendard는 Monaspace Argon Frozen의 Regular, Bold, Italic, Bold Italic을
영문·기호 원본으로 사용합니다. 영문 셀 메트릭을 고정하고, 패밀리 이름과 라이선스
메타데이터를 변경하며, 코딩 리게이처와 치환 테이블을 제거했습니다. 최종 패밀리
이름은 위 Reserved Font Name을 사용하지 않습니다. SIL Open Font License 1.1
전문은 루트 `LICENSE`에 있습니다.

## Pretendard 1.3.9

- 원본: https://github.com/orioncactus/pretendard
- 저작권: Copyright (c) 2021, Kil Hyung-jin
- 라이선스: SIL Open Font License 1.1
- Reserved Font Name: Pretendard

Pretendard의 한글·CJK 윤곽을 크기와 위치를 조정해 영문 두 칸 셀에 병합했습니다.
최종 패밀리 이름 `Argontendard`는 Reserved Font Name `Pretendard`를 사용하지 않습니다.
결과 폰트 전체는 SIL Open Font License 1.1로 배포됩니다.

## Nerd Fonts 아이콘

- 원본: https://github.com/ryanoasis/nerd-fonts
- 사용 버전: 3.4.0
- 라이선스 원문: `NERD_FONTS_LICENSE.txt`
- 라이선스 감사표: https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/license-audit.md

Nerd Fonts Symbols Only의 아이콘을 모든 결과 TTF에 병합하고 한 칸 고정폭으로
유지합니다.
Nerd Fonts 자체 소스와 Symbols Only 글꼴은 MIT로 분류되지만, 포함된 아이콘의
원본별 조건은 서로 다릅니다. 공식 감사표에 따라 Codicons와 Font Awesome은
CC BY 4.0, Material Design Icons는 Apache 2.0, Pomicons와 Weather Icons는
SIL Open Font License 1.1이며, 그 밖의 Devicons·Octicons·Powerline 계열 등은
각 원본의 MIT 또는 자유 라이선스 고지를 따릅니다. Argontendard는 해당 아이콘을
Nerd Fonts 3.4.0 배포본에서 가져와 크기와 셀 폭을 조정했습니다.

## Monatendard

- 원본: https://github.com/younjungpark/Monatendard
- 라이선스: SIL Open Font License 1.1

Argontendard는 Meslotendard와 Monatendard의 재현 가능한 다운로드, 한글 병합, 고정폭 검증과
패키징 구조를 바탕으로 대폭 수정한 포크입니다.

## Meslo LG 이전 고지

Argontendard 결과 TTF에는 Meslo LG 윤곽이 포함되지 않습니다. 포크 이력의 원본 고지를
삭제하지 않기 위해 이전 Meslotendard에서 보존하던 Apache License 2.0 전문을
`MESLO_APACHE-2.0.txt`에 그대로 유지합니다.

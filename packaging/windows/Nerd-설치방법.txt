Monatendard Nerd Font Mono Windows 설치 방법
============================================

공식 소개·체험·다운로드: https://monatendard.github.io/

이 패키지는 Oh My Posh, Powerlevel10k 등 Nerd Font 아이콘이 필요한 터미널용입니다.
일반 Monatendard와 별도 패밀리로 설치되므로 두 글꼴을 함께 사용할 수 있습니다.

설치
1. ZIP을 원하는 폴더에 완전히 압축 해제합니다.
2. Install-Monatendard-Nerd.ps1을 마우스 오른쪽 버튼으로 눌러 PowerShell로 실행합니다.
3. 실행 정책 안내가 나오면 PowerShell에서 다음 명령을 사용합니다.

   powershell -ExecutionPolicy Bypass -File .\Install-Monatendard-Nerd.ps1

4. 편집기와 터미널을 다시 시작한 뒤 글꼴을
   "Monatendard Nerd Font Mono"로 선택합니다.

제거
1. 같은 폴더에서 다음 명령을 실행합니다.

   powershell -ExecutionPolicy Bypass -File .\Uninstall-Monatendard-Nerd.ps1

2. 편집기와 터미널을 다시 시작합니다.

이 스크립트는 관리자 권한 없이 현재 Windows 사용자에게만 글꼴을 설치합니다.
Python, uv, Make는 필요하지 않습니다.
